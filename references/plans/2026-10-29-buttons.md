# Plan — Button component — 2026-10-29

## In short

The pages use three button looks: **Primary** (mint, filled), **Secondary** (outline) and **Tertiary** (text link with an arrow and an underline that grows on hover).
Figma's `secondary-white` and `back-button` are the same looks on a dark background: they become the Dark/Brand theme values of Secondary and Tertiary, not variants.
One component: the Lumos starter's `Button Main`, restyled in place. One `Icon Set` component with three icons (chevron right, arrow right, arrow left).

Source: Figma `Button` set (`2028:2112`, 5 types × rest/hover), scanned on every page frame of *Visual design* and *Mobile* with the kit's `figma-buttons-scan.js` (`[figma-only]`, `Components`, `Design components` and `Nav` frames skipped).

## 2. Component

| Topic | Choice |
|---|---|
| Component | `Button Main` (group Button), restyled in place; no second button component |
| Variants | `Primary` (base), `Secondary` (was starter Secondary), `Tertiary` (renamed from starter `Link`) |
| Not variants | hover (wrap `:hover` / `:focus-within` + trigger line), dark/brand version (theme variables), icon (Icon Set prop), icon-only round arrow (own component later), size (fluid/none: one size in the design) |
| Props | **Button**: Visibility, Variant, Text, Link · **Icon**: Icon Visibility (boolean, on), Icon (Icon Set variant, Designer link) · **Settings**: Clickable Visibility, Button Type |
| Icon Set | `icon_set_wrap` masked with the SVG, colour = `currentcolor`; variants Chevron Right (base), Arrow Right, Arrow Left |
| Icon position | right of the label on Primary/Secondary, left on Tertiary (`order` on the variant) — as on every page frame |
| Text | Primary/Secondary: Text Style mode **Text Medium** (18 / 1.5); Tertiary: base mode (16 / 1.5); weight `font/primary-medium` on the wrap |
| Box | `min-height: button-size/medium` (3rem = 48 px); padding 0 1rem on the element, 0 0.5rem on the label (Figma: 16 + 8 left, 8 + 16 around the icon); Tertiary `button-size/small` (2rem), no padding, gap 0.5rem |
| Lines | Secondary 2 px border (`0.125rem`); hover keeps 2 px (Figma draws 1 px on the filled hover state, same colour as the fill: no visible difference, no jump) |
| Radius | `radius/round` (Lumos default, matches 9999) |
| Colours | wrap carries background, text and border via `button-<look>/*` Theme variables; hover via `:hover` / `:focus-within` on the wrap |
| Themes | Dark and Brand modes of `button-secondary/*` take the `button-secondary-white/*` values; Dark and Brand modes of `button-tertiary/*` take the `button-back/*` values. The `-white` and `back` variables stay unused (kept for the Figma mapping). |
| Shadow | Primary: Figma's 5-layer drop shadow, smaller on hover; colours through a site-only theme variable `button-primary/shadow` |
| Tertiary line | `button_main_line` under the label, 1 px, colour `button-tertiary/accent` → `accent-hover`, scales from 0 to full width on hover (Figma: `Line` default → variant-2) |
| Motion | no motion guidelines in the file: colour 200 ms ease, line 600 ms `cubic-bezier(.65,.05,.36,1)` (kit defaults) |
