# Plan — Home «CTA» (CTA Split) — 2026-11-02

Aniek Velthuizen with Claude.

## In short

Builds the purple call-to-action card at the bottom of Home (photo left, «Looking for a senior project-controls expert?» + two buttons right) as a new section component **CTA Split**. It reuses Button Main (Primary + Secondary; on the purple card Secondary turns white by itself), Visual Image and the two-part title from Split Content. Nothing existing is changed. It goes at the end of Home's `page_main`, after Split Content #2. The same block is on 12 other page designs, so the texts, buttons, photo and top spacing are props.
**Status:** built 2026-11-02 after the owner re-pointed the claude.ai Webflow connector (component `0a616993-…`); see `decisions/components/cta-split.md` for what was measured and the one deviation (a `wbr` in the title).

Source: Figma `Content / CTA` (section `2323:32532`, set `content-cta` `2382:37326`, variants desktop `2236:5447` / mobile `2382:37327`). Dump in `references/figma/home-cta/` (`tree.txt`, `instances.txt`, PNGs, photo).
Page(s): Home — Figma page frame **1. Home B** (`2710:48615`), instance `2710:48623` (1512 × 612); mobile frame `1. Home`, instance `2382:37372`.
Insertion: Home › `page_main`, **after Split Content #2** (last child), before the Footer. Home B order: … Content block (643) → **CTA** (612) → Footer.
Neighbours' system: plain flat sections (`<name>_wrap.u-theme-*` › `_contain.u-container`), texts untrimmed with literal Figma gaps (Split Content), Space Top prop on Split Content (`large` / `main` / `none`).
Responsive: ≥ 992 two equal columns (photo | text), photo stretches to the text's height. < 992 one column, **text first, then the photo** at 26.25rem high (Figma mobile). Buttons wrap side by side when they fit; < 480 stacked (Figma mobile), left aligned, own width.

## Reuse

| Design section / element | Existing component | Decision | Reason |
|---|---|---|---|
| CTA band | `Split Content` | **new** (`CTA Split`) | Split Content is a text column next to a notched photo on white, with eyebrow/quote/list. The CTA is one coloured card with a flush photo, no notch, no eyebrow. Bending Split Content into this needs a card wrapper, a theme switch, a second image shape and hiding half its props — a variant that shares almost nothing. |
| Buttons «Request a shortlist» / «Discuss your project» | `Button Main` | place: Primary + Secondary | Secondary on the Brand theme = Figma `secondary-white` (`decisions/site.md`, buttons follow the theme) |
| Photo | `Visual Image` | place, variant that fills its box (cover) | same image component as Split Content |
| Title + muted second part | pattern from Split Content | copy the pattern (span + space + `_muted` span) | same title idea, muted colour here `swatch/light-100-o50` |

Structure:
```
section.cta-split_wrap.u-theme-light   data-section="light" data-cta-split data-space-top=<prop>
└─ cta-split_contain.u-container
   └─ cta-split_card.u-theme-brand      grid 1fr 1fr, radius/small, overflow clip, bg Theme background (brand-500)
      ├─ cta-split_visual               Visual Image, object-fit cover, fills the column (< 992: order 2, height 26.25rem)
      └─ cta-split_content.u-text-trim-off   flex column, padding 4rem (< 992: space/5), gap space/8
         ├─ div (title + text, gap space/4)
         │  ├─ h2.cta-split_title.u-text-style-h2  › span Title · " " · span.cta-split_muted (Title Muted)
         │  └─ p.cta-split_text.u-text-style-large
         └─ cta-split_actions            flex wrap, gap space/4 (< 480 column, align start)
            ├─ Button Main (Primary)
            └─ Button Main (Secondary)
```
