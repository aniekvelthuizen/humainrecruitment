## Unit (one)

`Stagger Cards`, built as a plain section the way Hero Experts is (site decision 2026-10-31: the API cannot reach anything nested inside a Lumos Section's slots, so the cards could not be set or fixed afterwards):

```
section.stagger-cards_wrap.u-theme-light  [data-section="light"] [data-stagger-cards]
  div.stagger-cards_contain.u-container
    div.stagger-cards_header                       centred, max 71.5rem, gap space/3
      p.stagger-cards_eyebrow.u-text-style-label-large   «The risk»            (prop Eyebrow + Visibility)
      h2.stagger-cards_title.u-text-style-h1             «One wrong hire costs » + span.stagger-cards_muted «more than a year of fees.»   (props Title, Title Muted)
      p.stagger-cards_text.u-text-style-main             subtitle               (prop Text + Text Visibility, default off)
    div.stagger-cards_list  [role="list"]          grid, 3 columns, gap space/7, items at the top
      Slot "Cards"  → 3 × Card Primary (Glass)
  HtmlEmbed (CSS): the step-down of the 2nd / 3rd card
```

Classes (all new, no prefix):

| Class | Properties |
|---|---|
| `stagger-cards_wrap` | `position: relative`; padding-top/bottom **8rem** (Figma 128, between steps: `section-space/main` 6 and `large` 12 — literal, noted); background-image radial gradient: ellipse 58.28 % × 52.94 % at 50 % 105.94 %, `glow/mint` at 49.5 % → transparent 100 %. ≤ 767: padding `section-space/main` (96), gradient as the mobile frame (162.5 % × 44.8 % at 50 % 87.3 %, from 10 %). |
| `stagger-cards_contain` | flex column, gap `space/8` (48), align centre |
| `stagger-cards_header` | flex column, gap `space/3` (10), `max-width: 71.5rem` (Figma 1144), width 100 %, text-align centre |
| `stagger-cards_muted` | `opacity: 0.5` |
| `stagger-cards_list` | grid, `grid-template-columns: repeat(3, minmax(0, 1fr))`, gap `space/7` (32), `align-items: start`, width 100 %. ≤ 991: one column, row gap `space/5` (20, Figma mobile) |
| embed CSS | ≥ 992: 2nd card `margin-top: space/8` (48), 3rd `section-space/main` (96), repeating for a 4th+ card (3n+2 / 3n) |

Responsive: ≥ 992 three columns stepping down as Figma. Below 992 one column, cards full width, no step (the mobile frame's layout) — three 210 px columns at 768 would squeeze the 24 px titles to 3–4 lines, and a 2 + 1 grid leaves the step meaningless. Title H1 shrinks fluidly to 36 on phones (site rule: a level keeps its own mobile size; Figma's mobile frame draws it as H4 30). Eyebrow stays Label Large at every width (Figma mobile uses Label 12; same one-system rule).

Props (folders in visual order): **Eyebrow** (Text, Visibility) · **Title** (Title, Title Muted) · **Text** (Text, Visibility, default off) · **Cards** (slot). Interactive parts: none (cards have no link — Figma none; hover/focus not applicable).

## Conflicts and slips

1. **Middle card is 263 high** (fixed in Figma), the other two hug their content at 226 — leaves an empty band at the bottom of card 2. → Q1.
2. **Glass ring**: the site's Glass card always draws a thin white gradient edge (About "Values" has it); this Figma card has none. On white / pale mint it is close to invisible. Recommend: keep the Glass variant as is (no new variant for an edge nobody sees); noted.
3. Card titles: the site's Glass card is 230 high where Figma is 226 (known, `decisions/components/cards.md`).
4. Glow colour `#00e5e5` is not in the palette → new Theme variable `glow/mint` (Base/Dark/Brand same value).
5. Section padding 128 is off the section-space scale → literal 8rem, noted.
6. Build route: plain section instead of the kit's Lumos Section build-up (same deviation as Hero Experts, same reason). → Q2.
