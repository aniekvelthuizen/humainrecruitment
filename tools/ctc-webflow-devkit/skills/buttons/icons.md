# Icons — one `Icon Set` component, the icon chosen by variant

Every icon of the Figma icon set becomes one variant of a single component. The element is a box filled with the text colour and masked by the icon's SVG, so the icon follows the button's colour, the section's theme and the hover state, and one instance carries one icon (not every SVG hidden in the DOM).

```
Icon Set (group SVG)     class icon_set_wrap     aria-hidden="true"
  display: block; width: 100%; aspect-ratio: 1/1; flex-shrink: 0;
  background-color: currentcolor;
  mask-image: url('<asset url>'); mask-size: contain; mask-repeat: no-repeat; mask-position: center;
Variants: base = the most used icon (usually the arrow); one per other icon, overriding only mask-image.
```

Size comes from the parent (`button_main_icon` width), colour from `color`. The same component serves cards, lists and links later.

## 1. Export the SVGs clean

- **Preferred:** Figma Plugin API through `use_figma` — `node.exportAsync({ format: 'SVG_STRING', svgIdAttribute: false })` per variant returns a clean icon. The tool output is capped near 20 KB, so export in batches by size and write each SVG to a file in the session scratchpad.
- **Alternative:** `download_assets` with `defaultFormat: "svg"` per variant node. These exports include the **component-set background square and its dashed purple outline**; as a mask that renders a solid square. Strip them with [scripts/clean-icons.py](scripts/clean-icons.py) (removes the full-size background `<rect>`, any `stroke="#9747FF"` rect, and `id`s) and check that no `<rect>` with those colours is left. Legitimate rects inside an icon stay.
- Keep the Figma names (`arrow-outward-cta.svg`). Note any icon that is not square (a 24 × 26 frame is a design slip; the mask keeps its proportions).

## 2. Upload

`asset_tool > upload_image_by_url` needs a public URL; `download_assets` URLs work but are the unclean ones. For cleaned files use `data_assets_tool > create_asset` (MD5 of the file, name `icon-<name>.svg`) for all icons in one call, save the response to a file, and run [scripts/upload-assets.py](scripts/upload-assets.py): it posts every file to S3 with the returned form fields and writes `name → hostedUrl` to a JSON file. Expect HTTP 201 per file.

A mask loaded from another domain needs CORS. Check once: `curl -sI -H "Origin: https://<site>.webflow.io" <hostedUrl> | grep -i access-control` → `access-control-allow-origin: *` on Webflow's asset CDN.

## 3. Build the component

1. `data_style_tool > create_style` `icon_set_wrap` with the base mask (read the URL from the JSON, never type it).
2. Create one `DivBlock` with that class (+ `aria-hidden="true"`) on the Styleguide, `transform_element_to_component` → name `Icon Set`, group `SVG`, `replace: false`; remove the page element.
3. `set_variant_name` base → the base icon's name; `create_variant` for every other icon in one call (names: Figma names in Title Case); then `set_variant_styles` `mask-image` per variant in one call, generated by script from the JSON.
4. Read back two or three variants with `get_variant_styles`.
5. Put an instance inside `button_main_icon` in the button definition; link its Variant to a button prop **Icon** in the Designer (SKILL.md §3).

## 4. Verify

The Designer snapshot draws masks as solid squares. Render a contact sheet of every icon in a browser (a local HTML page with one `icon_set_wrap` per URL, headless Chrome screenshot) and look at all of them once. Then check one button per theme on the page.

## 5. Adding an icon later

Export → clean → upload → `create_variant` → `set_variant_styles` mask-image → record the name in `decisions/components/icon-set.md`.
