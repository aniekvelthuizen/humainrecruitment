# Source: a copy document

The document is the source for text and order. The site's system is the source for typography and spacing. Figma is the source for labels and structure. When two disagree, ask.

1. **Extract everything** to `references/copy/<page>.md`, section by section, in document order. PDF: `pdftotext -layout` for text, `pypdf` annotations (`/Annots` → `/A` → `/URI`) for links, `/BaseFont` containing `Bold` for bold runs. Word (`.docx`): text with `pandoc -t markdown` (keeps bold and links) or `textutil -convert txt` on macOS; then `unzip` it and read `word/comments.xml` (each `<w:comment>`'s `<w:t>` runs) and match every comment to its text through `commentRangeStart`/`commentRangeEnd` in `word/document.xml`. Comments are instructions, not copy ("hide at launch", "copy for the menu", "see the Excel file"), and so are notes typed in the body in the client's language. Look at every image in `word/media` (a chart or a mock-up is often the only source for a section). Formatting is content; links are content.
2. **Show the file** and let the user check it before anything touches the page. With it, one round of open points ([asking.md](${CLAUDE_PLUGIN_ROOT}/references/asking.md)): copy that is missing or still lorem, two versions of the same block, numbers that contradict each other (a results paragraph copied from another trial), names used two ways — and the typo fixes you will make yourself unless they object.

   A whole-site document: one `references/copy/<page>.md` per page (the page's lines plus the comments on them), a plan with the shared rules and the decisions taken on the open points, then one builder agent per page group in parallel. Texts the API cannot reach (closed components, hidden form steps) go to the Designer queue.
3. **Inventory** document section → page element → status (present, lorem, missing, bound to a prop). Missing sections are a plan question.
4. **Fill.** `set_text` on plain elements, the prop value on component instances (`set_text` on a bound element fails), `data_whtml_builder` for paragraphs with links or bold. Empty blocks are hidden with a boolean prop, never left as placeholders. Before adding a callout or stat, text-filter the page for its key sentence: duplicates happen.

   CMS: real items replace dummies. Drafting an item does not take it off the live site; unpublish the dummies, and publish the edited items explicitly. Then check the native conditions in the list's card ("Company is set"): a condition on a field the real items leave empty hides every one of them (Forest3: five real reviews rendered as an empty list). A dummy still referenced elsewhere (an author on an article) is moved to a real item first.
5. **Compare 1:1**, literally, including order, against `references/copy/<page>.md`. "Already correct" has turned out to be lorem on the second tab. Then a formatting pass, and a scan for text props with `hasOverride: false` that should have been overridden.
